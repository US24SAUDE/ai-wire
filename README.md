# AI Wire

Portal de notícias de Inteligência Artificial em português, inspirado no modelo Tom's Hardware.

## Stack
- HTML estático + CSS + JS vanilla (MVP)
- Deploy: Netlify
- Código: GitHub (US24SAUDE/ai-wire)

## Estrutura
- `/` — Homepage com hero, grid de cards, sidebar trending e newsletter
- `/artigos/` — Páginas de artigo com markdown, código e relacionados
- `/categorias/` — Páginas de categoria filtradas

## Categorias
Frameworks · Modelos · Agentes · Open Source · Guia do Dev · Análises · Benchmarks

## Roadmap
- v1 (este MVP): homepage, categorias, artigo, busca, dark mode, newsletter, trending
- v2: benchmarks vivos, comentários, perfis de autor, RSS
- v3: auto-agregação com LLM, newsletter automatizada
